# Baby Sage Skill

Baby Sage extracts reusable lessons from development work and applies them to future tasks.

## When to Use

- Use when a development task has a meaningful outcome to reflect on.
- Use when previous experience may improve the current task.
- Do not use this skill to modify Hermes itself.

## Procedure

1. Understand the current task and intended outcome.
2. Review relevant prior experience when available.
3. Perform or evaluate the development work.
4. Identify what caused important successes or failures.
5. Extract a general, reusable lesson.
6. Apply the lesson to future related tasks.

## Verification

- The lesson must describe a reusable principle rather than a single incident.
- The lesson must be supported by the observed task outcome.
- The current task must remain unchanged unless another instruction explicitly permits modification.
